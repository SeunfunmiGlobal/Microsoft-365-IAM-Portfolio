# Microsoft Entra ID — Identity & Access Management

**Portfolio area:** Identity & Access Management (IAM)  
**Role represented:** Identity & Microsoft Cloud Administrator  
**Technologies:** Microsoft Entra ID, Active Directory, MFA, Conditional Access, RBAC, Microsoft 365

## Project overview

An anonymised case study covering identity administration and access-security support in Microsoft Entra ID environments. The focus is on user and group administration, authentication, access controls, identity synchronisation, and troubleshooting.

> **Portfolio note:** This case study summarises the responsibilities and capabilities described in my professional background. Specific customer configurations and tenant information are not disclosed. Only describe individual changes as completed where you can verify your involvement.

## Scope of work

- Administered and supported user and group identities.
- Supported Multi-Factor Authentication (MFA) configuration and authentication troubleshooting.
- Assisted with Conditional Access policy administration and access issues.
- Supported identity synchronisation and hybrid identity troubleshooting.
- Resolved sign-in, authentication, and access-related incidents.
- Supported Active Directory and cloud identity administration.
- Applied role-based access principles when administering access.

## Technical approach

1. Confirmed the affected identity, sign-in context, and scope of the access issue.
2. Reviewed user state, group membership, assigned roles, and relevant identity attributes.
3. Checked authentication methods and MFA registration or challenge behaviour.
4. Reviewed applicable Conditional Access outcomes and sign-in diagnostics.
5. Investigated directory synchronisation or hybrid identity dependencies where relevant.
6. Applied or recommended least-privilege remediation and validated the resulting access behaviour.

## Business value

The work supports more controlled identity administration, stronger authentication practices, clearer access governance, and more reliable user access to Microsoft cloud services.
