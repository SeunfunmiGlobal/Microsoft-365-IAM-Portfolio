## Project overview

An anonymised case study describing endpoint administration and support using Microsoft Intune and Microsoft Entra ID. The work focuses on device enrolment, configuration, compliance visibility, endpoint security, and troubleshooting across Microsoft-managed Windows devices.

> **Portfolio note:** This case study is based on the type of endpoint administration and support described in my professional experience. Customer and tenant details are intentionally omitted. Add only screenshots and outcomes that you can personally verify and safely disclose.

## Scope of work

- Supported Windows device enrolment and endpoint registration.
- Created, reviewed, and deployed device configuration profiles.
- Configured and troubleshot device compliance policies.
- Supported endpoint security and secure-access policy administration.
- Investigated enrolment, synchronisation, policy deployment, and device compliance issues.
- Worked with Microsoft Entra ID device identity and access controls.

## Technical approach

1. Confirmed device ownership, operating-system requirements, and enrolment prerequisites.
2. Reviewed the relationship between Microsoft Entra ID registration/join state and Intune enrolment.
3. Applied configuration and compliance policies to appropriately scoped device/user groups.
4. Monitored device check-in, policy application, and compliance status.
5. Investigated failed enrolments, stale device records, configuration conflicts, and synchronisation issues.
6. Validated the expected device and access state after remediation.
